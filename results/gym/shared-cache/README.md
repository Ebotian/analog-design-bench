# Shared-cache runs (cost figures not comparable)

These runs used one cache directory across budgets, so a repeated budget
replayed earlier evaluations for free.  The `sims` field therefore measures
*new* simulations, not search effort, and the numbers here cannot be compared
with `ladder-*/` or `calibrated-*/`, which give every run its own cache.

Kept because the outcomes (margins, official verdicts) are still valid; use
`ladder-3200/` and `ladder-6400/` for any cost or rate claim.
